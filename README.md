# Canvas App

A simple interactive canvas app built with **React**, **TypeScript**, and **Vite**.

## ✨ Features

- 🎨 **Background Fill Tool**  
  Select a color and click anywhere on the canvas to fill the background.

- 🟢 **Shape Tool**  
  Choose a color and shape, then draw it on the canvas using your cursor.  
  Shapes can also be **dragged** around after being drawn.

## 🚀 Getting Started

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Open your browser at the URL shown in the terminal to launch the app.
